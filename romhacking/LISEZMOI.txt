Gran Turismo 2 (PS1, PAL) - Menu de triche en surimpression v1.0
================================================================
par soaresden - https://github.com/soaresden/GranTurismo2-OverlayCheat

Maintenir SELECT (ou appuyer L1 + R1 + L2 + R2 ensemble) : un petit menu apparaît par-dessus le
jeu :

  FREEZE TIMER   arrête le chronomètre des permis
  MONEY          change les crédits en direct (pas réglable, maximum, zéro)

Commandes (manette 1)
---------------------
Deux façons d'ouvrir le menu « GT2 CHEAT » :
  - SELECT maintenu : le menu apparaît après un court instant et disparaît quand on relâche ;
  - L1 + R1 + L2 + R2 ensemble : le menu s'ouvre et reste ouvert ; START (ou les quatre
    gâchettes à nouveau) le referme. À utiliser dans RetroArch / Batocera, où SELECT est souvent
    la touche « hotkey ».
Tant que le menu est ouvert, le jeu ne reçoit plus la manette.

  Haut / Bas                    choisir la ligne
  Ligne FREEZE TIMER :
    Gauche / Droite / Croix / Rond   ON / OFF
  Ligne MONEY :
    Droite / Gauche             + / - le pas (maintenu : répétition)
    R1 / L1                     pas x10 / pas ÷10 (de 1 à 10 000 000)
    Triangle                    99 999 999 (le maximum)
    Carré                       0

- FREEZE TIMER ON : dans un permis, le chrono s'arrête là où il est. S'il était déjà ON au
  départ, il s'arrête à 0:00.040, juste après le départ (un permis dont le chrono reste à 0 ne se
  termine jamais). Arrêtez-vous dans la zone : l'or est à vous. Le choix est gardé jusqu'à
  l'extinction. N'agit que dans les permis, pas en course.
- Un appui bref sur SELECT (sans autre touche) est rendu au jeu quand on le relâche.

Appliquer le patch
------------------
Sur le disque Simulation (disque 2, SCES-12380, « Gran Turismo Mode »), avec l'un des deux :
  Gran Turismo 2 (Europe) (Disc 2) [Overlay Cheat].ppf     (PPF 3.0, octets modifiés seulement)
  Gran Turismo 2 (Europe) (Disc 2) [Overlay Cheat].xdelta  (xdelta3)

Image d'origine : un .bin d'une piste, 2352 octets par secteur :
  Gran Turismo 2 (Europe) (En,Fr,De,Es,It) (Disc 2) (Gran Turismo Mode).bin
  Taille 710 226 384 octets
  CRC32  64439308
  SHA-1  c63a53bcf5ac6e49547a0c95b05174deff172021
Image patchée :
  CRC32  41B7DCB9
  SHA-1  9fe8e1acf3819398fc4849efc26bbf0f4601cd93

Disque combiné (GT2-Combined-Disc) et GT2 Plus : leur organisation diffère, utilisez l'outil
Python du projet (patch_disc.py, Python 3, rien à installer), qui prend un .chd, .cue ou .bin et
vérifie chaque mot avant de le changer :
  python patch_disc.py "Gran Turismo 2.chd"

Essayé dans PCSX-Redux (BIOS SCPH-5502 et OpenBIOS) et dans RALibretro / RetroArch avec le cœur
Beetle PSX, sur le disque combiné d'origine et sur GT2 Plus beta 7 combiné.
